# Reaction Core

Внутрішня платформа компанії Reaction — робоча назва (розвідка, аналітика, ІТ, кібербезпека, операції, академія).
Матовий чорний корпоративний стиль, знак «волошка» як логотип та індикатор завантаження.

## Модулі

- **Огляд** — ключові метрики: звіти за 8 класами джерел, завершені оцінки, запити на доступ, сховище, MFA, стан систем, активність.
- **Напрями** — структура компанії, керівники, люди, проєкти й папки кожного напряму.
- **Доступи** — люди (роль, напрям, рівень допуску, MFA, статус), запити на доступ зі схваленням, матриця ролей і прав, рівні допуску.
- **Сховище** — папки та файли з грифами; реальне завантаження файлів (зберігаються в IndexedDB на пристрої), перегляд, завантаження, видалення; файли вище допуску користувача замасковано.
- **Карта** — детальна карта світу (Natural Earth 1:50m, на наближенні 1:10m) з українськими назвами країн і Кримом у складі України.
  Координати під курсором у форматах DD, DMS і MGRS; пошук за координатами, MGRS, містом, країною чи позначкою; позначки з грифами;
  вимір відстаней по великому колу з азимутами; відстеження рухомих об'єктів зі слідом, курсом, часом прибуття й режимом «стежити»;
  шар зон збройних конфліктів (напівпрозорий червоний): тимчасово окуповані території України (Крим, Донбас, південь) та інші зони — орієнтовно.
- **Журнал аудиту** — кожна дія фіксується, пошук, фільтр, експорт у CSV.
- **Налаштування** — профіль, запит на підвищення допуску, тема (Матова чорна / Папір), приховування чутливих показників, автоблокування.

Також: сповіщення (запити, що чекають рішення, і відповіді на власні), доступ до папки після схвалення запиту, блокування, що зберігається після перезавантаження, глибокі посилання з командного рядка. Заставка з волошкою, вхід у два кроки (пароль + 2FA), екран блокування (Ctrl+L), командний рядок (Ctrl+K), адаптивність для телефона.

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # збірка в dist/
```

## Важливо

Це фронтенд-прототип: дані демонстраційні й зберігаються в браузері (localStorage + IndexedDB), автентифікація імітована.
Для реального використання потрібні сервер, справжня автентифікація (SSO/MFA), перевірка прав на бекенді та шифроване сховище.

## Дані карти

`node scripts/build-map.mjs` перебудовує `src/data/world-50m.json` і `world-10m.json` з пакета `world-atlas`:
повертає Крим до складу України (Natural Earth малює його в складі Росії), виправляє вивернуті полігони й додає українські назви.
Зони конфліктів — `src/data/conflicts.js`: межі орієнтовні, оновлюйте їх з перевірених джерел (DeepState, ISW, ACLED).

## Бренд

`brand/gen-mark.mjs` генерує векторний знак-волошку (`brand/out/*.svg`, `src/brand/mark-paths.json`).
Це векторна реконструкція за брендбуком; за наявності оригінального майстер-файлу SVG його слід підставити замість цього.
